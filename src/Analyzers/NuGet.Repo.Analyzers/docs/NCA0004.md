# NCA0004

See the [documentation on the category of string comparisons for more context](./CaseSensitiveStringComparisons.md).

Warns on string equality comparisons that do not use an explicit comparer. Prefer `IEqualityComparer<string>.Equals(x, y)` with a `StringComparer`.

It flags:
- Instance `string.Equals(string)` and static `string.Equals(string, string)` (without a `StringComparison` parameter).
- `object.Equals(object)` when invoked on a `string` receiver.
- Static `object.Equals(object, object)` when any argument is a `string`.
- Binary `==` and `!=` when either side is a `string` (excluding checks against `null` or empty).

Recommended: use `StringComparer` (for example, `StringComparer.OrdinalIgnoreCase.Equals(x, y)`) and avoid culture-sensitive comparisons.
