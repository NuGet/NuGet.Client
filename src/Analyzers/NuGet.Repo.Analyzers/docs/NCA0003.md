# NCA0003

See the [documentation on the category of string comparisons for more context](./CaseSensitiveStringComparisons.md).

Warns when creating `HashSet<string>` or sets of `string` without an explicit comparer.

It flags the following scenarios when the element type is `string` and no comparer is supplied:
- `new HashSet<string>(...)` and other types implementing `ISet<string>` if a constructor overload exists that accepts `IEqualityComparer<string>`.
- `ImmutableHashSet.Create<T>`, `CreateRange<T>`, and `CreateBuilder<T>` when producing `ImmutableHashSet<string>` without a `StringComparer`/comparer argument.
- LINQ `ToHashSet(...)` and `ToImmutableHashSet(...)` when producing sets with `string` elements and no comparer argument.

A comparer is considered present if you pass `StringComparer` (for example, `StringComparer.OrdinalIgnoreCase`) or any `IEqualityComparer<string>` instance.
