# NCA0002

See the [documentation on the category of string comparisons for more context](./CaseSensitiveStringComparisons.md).

Warns on calls to `string.GetHashCode()` and similar when the receiver is a `string`. Use `StringComparer.GetHashCode(string)` to ensure consistent, explicit comparison behavior.

It flags:
- `str.GetHashCode()` or `str?.GetHashCode()` when `str` is a `string` (including cases that resolve to `object.GetHashCode` on a string).

Recommended: use an explicit `StringComparer` (for example, `StringComparer.OrdinalIgnoreCase.GetHashCode(str)`).
