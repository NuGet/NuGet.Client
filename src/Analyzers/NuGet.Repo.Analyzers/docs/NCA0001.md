# NCA0001

See the [documentation on the category of string comparisons for more context](./CaseSensitiveStringComparisons.md).

Warns when creating dictionaries with `string` keys without an explicit comparer, to prevent case-sensitivity bugs.

It flags the following when the key type is `string` and no comparer is supplied:
- `Dictionary<string, TValue>` and other types implementing `IDictionary<string, TValue>` (including `ConcurrentDictionary<string, TValue>`) if a constructor overload exists that accepts `IEqualityComparer<string>`/`IComparer<string>`.
- `ImmutableDictionary.Create`, `CreateRange`, and `CreateBuilder` when producing `ImmutableDictionary<string, TValue>` without a `StringComparer`/comparer argument.
- LINQ `ToDictionary(...)` and `ToImmutableDictionary(...)` when producing dictionaries with `string` keys and no comparer argument.

A comparer is considered present if you pass `StringComparer` (for example, `StringComparer.OrdinalIgnoreCase`) or any `IEqualityComparer<string>`/`IComparer<string>` instance.
